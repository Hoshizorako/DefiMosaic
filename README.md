# DefiMosaic

Watches real-time DeFi metrics and liquidity pool updates for cryptocurrency traders and investors.

The key benefits of using DefiMosaic include:

- Watches real-time DeFi metrics and
- liquidity pool updates for cryptocurrency
- traders and investors

- Watches real-time DeFi metrics and

## Technology Stack

- javascript
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/DefiMosaic.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DefiMosaic is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
